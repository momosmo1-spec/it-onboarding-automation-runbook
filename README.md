# IT Onboarding Automation Runbook (Cybersecurity & Systems)

## Overview
This project documents a complete IT onboarding process for new employees, focusing on secure system configuration using Active Directory, Group Policy, and PowerShell.

It simulates a real-world enterprise environment where new users must be provisioned with proper access controls and security policies.

## What This Project Covers
- Domain setup and machine configuration
- User account creation in Active Directory
- Department group creation and access control
- Shared folder setup with permissions
- Organizational Unit (OU) structuring
- Group Policy Object (GPO) configuration
- Login scripts and system restrictions
- Event log verification
- PowerShell automation for system checks

## Key Features
- Secure user onboarding workflow
- Role-based access control using groups
- GPO enforcement for system security
- Automated service and system reporting

## Skills Demonstrated
- Active Directory administration
- Group Policy configuration
- PowerShell scripting
- IT system provisioning
- Security best practices
- Enterprise system thinking

## Tools & Technologies
- Windows Server
- Active Directory
- Group Policy Management
- PowerShell
- Event Viewer

## Real-World Application
This project reflects how organizations onboard new employees securely while maintaining system integrity and enforcing company policies.
